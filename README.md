#Snake Game

A snake game built on Python with Pygame.

#Author Jemma Little
With help from geeksforgeeks.com for teaching me the basics of Pygame
https://www.geeksforgeeks.org/python/pygame-tutorial/

#Requirements
Python 3.12 
Pygame 2.6.1

#Installation
pip install -r requirements.txt

#Development
All development was completed on Windows 11, Pygame 2.6.1, Python 3.12

#To Start 
use command:
Python src/main.py

#All Music
was performed and this use was licensed by Alex McCulloch. 

#Controls
All control will be done with the Arrow Keys. Avoid obstacles and yourself while eating fruit in your quest for the highest score!

#V1.0 Features
Grid based movement
Randomized fruit colors
Growing snake
A high score display
Game over screen
